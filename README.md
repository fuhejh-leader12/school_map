# 福和國中智慧校園導覽｜手機測試版

此資料夾為可獨立發布的靜態網站，包含最新分段導覽與手指點按轉乘標籤。起點固定一樓川堂。

## 發布至GitHub Pages

1. 先確認校園地圖、班級與場地位置可公開瀏覽，並決定GitHub儲存庫。
2. 將本資料夾內的檔案及assets、runtime資料夾上傳到該儲存庫根目錄；index.html須直接位於根目錄，不要再多包一層資料夾。
3. 在Settings → Pages選擇Deploy from a branch、main分支及/(root)。若分支名稱不同，選實際上傳的分支。
4. 儲存後等待GitHub Pages完成發布，再使用頁面顯示的實際HTTPS網址。

一般專案網址為https://帳號.github.io/儲存庫名稱/；此為格式示意，尚不是本專案實際測試網址。

GitHub Pages一般公開可讀。私有儲存庫不等於私人網站，若只限特定校內同仁，須另行規劃存取控制。

此資料夾不含Excel維護表、歷年備份、現場驗收截圖或本機伺服器設定。地圖與路線所需的網站資料仍會被瀏覽器下載，請視為公開內容。字體授權保留於assets/fonts/OFL-LICENSE.txt。

## 手機測試

以手機Safari或Chrome透過4G／5G開啟發布網址，測試首頁、目的地選取、縮放拖曳、728的1F→2F→4F、科技中心1F→3F、演藝廳1F→5F，以及點按橘色手指轉乘標籤。完整路線說明可展開。

目前已通過手機瀏覽器模擬，實體手機驗收仍待執行。

學年度更新仍在本機維護Excel並產生新資料，再重新整理發布檔案與上傳；不需要把Excel本身上傳到網站。
