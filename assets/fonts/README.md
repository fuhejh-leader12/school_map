# 1F地圖字體

來源：justfont官方open-huninn-font專案，font/jf-openhuninn-2.1.ttf。
https://github.com/justfont/open-huninn-font

原始TTF以SIL Open Font License 1.1釋出，授權全文保留於OFL-LICENSE.txt。未修改字體、未改字形、未子集化或轉換字體格式；完整原始TTF直接以Base64嵌入SVG。來源與SHA-256見source.json。

map-font.js由build-map-font.cjs自動產生。訪客不必安裝字體，也不必連線外部字體服務。傳送網站資料夾時請保留整個assets/fonts，以保留字體、授權及嵌入資源。

CSS名稱FuheHuninn僅為網頁內部字體選取別名，不是修改或重新命名字體檔；瀏覽器實際字體名稱仍為jf open 粉圓2.1。
